🚀 **Just launched: Resume Ecosystem – An Intelligent, Event-Driven Career Platform**

I'm excited to announce my latest open-source project: **Resume Ecosystem**.

It’s a next-generation resume builder that automatically generates **verified resumes** from real achievements. Instead of manually typing "Completed Coursera Course", the system *verifies* your certificate and updates your resume in real-time.

**Under the hood:**
🔹 **Architecture:** Event-Driven Microservices (8 services)
🔹 **Backend:** Node.js 20, TypeScript, Fastify, Prisma
🔹 **Messaging:** Kafka (for loosely coupled communication)
🔹 **Database:** PostgreSQL + Redis
🔹 **Frontend:** React + Vite
🔹 **Infrastructure:** Docker Compose + Kubernetes Helm Charts

This project solves the problem of unverifiable and outdated resumes. It connects directly with platforms like GitHub (via webhooks) and online learning systems to build a **Proof of Skill** portfolio.
